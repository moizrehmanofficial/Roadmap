## What is it?

A function is a reusable named block of code that performs a specific task. It can accept inputs (parameters), execute logic, and return an output value.

## Why does it matter?

Functions are the primary tool for avoiding code repetition (DRY principle) and creating abstraction. They allow you to name a process and call it anytime.

## When and where do you use it?

Whenever you have logic you use more than once, or logic complex enough to deserve a name. In React, every component is a function.

## How does it work?

Define once with function keyword or arrow syntax, call many times. Parameters go in (), body in \{\}, return sends a value back to the caller.

## Examples

### 4 ways to write a function

```javascript
// 1. FUNCTION DECLARATION — hoisted, can call before definition
function greet(name) {
  return "Hello, " + name;
}
console.log(greet("Sam")); // "Hello, Sam"

// 2. FUNCTION EXPRESSION — NOT hoisted, stored in variable
const greetExpr = function(name) {
  return "Hello, " + name;
};

// 3. ARROW FUNCTION — modern, concise, no own "this"
const greetArrow = (name) => {
  return "Hello, " + name;
};

// 4. ARROW — short form (single expression = implicit return)
const greetShort = (name) => "Hello, " + name;

// One parameter — parens optional
const double = n => n * 2;
console.log(double(5)); // 10

// No parameters — parens required
const sayHi = () => "Hi!";
```

### Default params, rest, spread, callbacks

```javascript
// Default parameters
function greet(name = "World", greeting = "Hello") {
  return `${greeting}, ${name}!`;
}
greet();            // "Hello, World!"
greet("Sam");       // "Hello, Sam!"
greet("Sam", "Hey") // "Hey, Sam!"

// Rest parameters — collect remaining args into array
function sum(...numbers) {
  return numbers.reduce((total, n) => total + n, 0);
}
sum(1, 2, 3, 4); // 10

// Spread — expand array into arguments
const nums = [3, 1, 4, 1, 5, 9];
Math.max(...nums); // 9 (same as Math.max(3, 1, 4, 1, 5, 9))

// Callback — function passed to another function
[1, 2, 3].forEach(function(num) {
  console.log(num);
});

// Arrow callback (most common form)
[1, 2, 3].map(num => num * 2); // [2, 4, 6]

// Higher-order function — returns a function
const makeAdder = (x) => (y) => x + y;
const add5 = makeAdder(5);
add5(3); // 8
add5(10); // 15
```

## Key terms

<Terms>
  <Term name="Parameter">Variable in function definition: function greet(name) — name is a parameter</Term>
  <Term name="Argument">Actual value passed when calling: greet('Sam') — 'Sam' is the argument</Term>
  <Term name="Return value">The value a function sends back with the return keyword</Term>
  <Term name="Pure function">Always returns same output for same input, no side effects — predictable and testable</Term>
  <Term name="Callback">A function passed as an argument to another function, to be called later</Term>
  <Term name="Higher-order function">A function that takes another function as argument or returns one (map, filter, reduce)</Term>
</Terms>
