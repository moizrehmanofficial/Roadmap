## What is it?

Scope defines the region of code where a variable is accessible. Closure is when an inner function 'remembers' variables from its outer function even after the outer function has finished running.

## Why does it matter?

Scope prevents naming conflicts between variables. Closures enable powerful patterns like data privacy, factory functions, and React hooks under the hood.

## When and where do you use it?

Scope applies everywhere you write code. Closures are used in event handlers, setTimeout callbacks, React's useState and useEffect, and any function returned from another function.

## How does it work?

JavaScript uses lexical scoping — scope is determined by where you WRITE the code, not where it runs. Inner functions can always access outer variables, but not vice versa.

## Examples

### The 3 types of scope

```javascript
// 1. GLOBAL SCOPE — accessible everywhere
const globalVar = "I'm everywhere";

function example() {
  console.log(globalVar); // ✅ works
}

// 2. FUNCTION SCOPE — only inside the function
function myFunction() {
  var functionScoped = "only in here";
  console.log(functionScoped); // ✅ works
}
// console.log(functionScoped); // ❌ ReferenceError

// 3. BLOCK SCOPE — only inside {}
{
  const blockScoped = "only in this block";
  let alsoBlock = "me too";
  console.log(blockScoped); // ✅ works
}
// console.log(blockScoped); // ❌ ReferenceError
```

### Closures — function remembers its birthplace

```javascript
// Inner function remembers outer function's variables
function createCounter() {
  let count = 0; // this variable is "closed over"
  
  return function() {
    count++; // accesses count even after createCounter() finished!
    return count;
  };
}

const counter = createCounter(); // createCounter() has returned
console.log(counter()); // 1
console.log(counter()); // 2 — count is remembered!
console.log(counter()); // 3

// Real-world: React useState uses closures internally
// Each component instance has its own closed-over state

// Practical closure example
function makeMultiplier(multiplier) {
  return (number) => number * multiplier; // closes over multiplier
}

const double = makeMultiplier(2);
const triple = makeMultiplier(3);

console.log(double(5));  // 10
console.log(triple(5));  // 15
```
