## What is it?

Variables are named containers that store data values in memory. JavaScript has three ways to declare them: var, let, and const — each with different rules about scope and reassignment.

## Why does it matter?

Without variables, you cannot store or reuse any information. They are the single most fundamental building block of any program.

## When and where do you use it?

Every time you need to save a value — user input, API result, counter, flag, configuration. Variables live in 'scope' — the region of code where they are accessible.

## How does it work?

Declare with var, let, or const followed by a name, then optionally assign a value with =. Always prefer const by default, use let when the value will change, and avoid var in modern code.

## Examples

### var — old way (avoid in modern code)

```javascript
// var is function-scoped and gets hoisted
var name = "Ali";
var name = "Ahmed"; // ✅ No error — var ALLOWS re-declaration (dangerous!)

// Hoisting example — var is mentally moved to the top
console.log(age); // undefined (NOT an error — this is the bug trap!)
var age = 25;
console.log(age); // 25

// var ignores block scope — this is why it's dangerous
if (true) {
  var leaksOut = "I escape the block!";
}
console.log(leaksOut); // "I escape the block!" — oops!
```

### let — block-scoped mutable variable

```javascript
// let respects block scope and can be reassigned
let score = 0;
score = 10; // ✅ Allowed — let CAN be reassigned

// Block scope — variable dies when the block ends
if (true) {
  let blockVar = "inside only";
  console.log(blockVar); // ✅ "inside only"
}
// console.log(blockVar); // ❌ ReferenceError — not accessible here

// Perfect for loop counters
for (let i = 0; i < 3; i++) {
  console.log(i); // 0, 1, 2
}
// console.log(i); // ❌ ReferenceError — i is gone
```

### const — constant reference (use by default!)

```javascript
// const CANNOT be reassigned after declaration
const API_URL = "https://api.example.com";
// API_URL = "other"; // ❌ TypeError: Assignment to constant variable

// ⚠️ IMPORTANT: const objects/arrays CAN have their contents changed!
const user = { name: "Ali", age: 25 };
user.name = "Ahmed"; // ✅ ALLOWED — changing a property, not the variable
user.role = "admin"; // ✅ ALLOWED — adding a property
// user = {}; // ❌ ERROR — cannot reassign the variable itself

const colors = ["red", "green"];
colors.push("blue"); // ✅ ALLOWED — modifying array contents
// colors = []; // ❌ ERROR

// Use const for: config values, imported modules, object/array references
const MAX_RETRY = 3;
const baseURL = "https://api.example.com/v1";
```
