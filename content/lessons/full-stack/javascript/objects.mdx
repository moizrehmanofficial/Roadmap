## What is it?

An object is a collection of key-value pairs that groups related data and functionality. Keys are strings (or symbols), values can be anything.

## Why does it matter?

Objects model real-world entities. Every API response, React props, component state, and database row is an object. Mastering objects is essential.

## When and where do you use it?

Constantly. config objects, API response parsing, component props, function parameters that accept options, state management.

## How does it work?

Create with \{\} syntax. Access with dot notation (obj.key) or bracket notation (obj['key']). Destructure to extract values into variables cleanly.

## Examples

### Objects: creation, access, methods

```javascript
// Object literal
const user = {
  id: 1,
  name: "Sam",
  age: 25,
  isAdmin: false,
  address: {              // nested object
    city: "Austin",
    country: "USA"
  },
  greet() {               // method (function as property)
    return `Hi, I'm ${this.name}`;
  }
};

// Accessing properties
user.name;             // "Sam" — dot notation
user["age"];           // 25 — bracket notation (dynamic keys)
user.address.city;     // "Austin" — nested access

// Dynamic key access
const key = "name";
user[key];             // "Sam" — variable as key

// Modifying
user.age = 26;         // change existing
user.email = "sam@example.com"; // add new property
delete user.isAdmin;   // remove property

// Check if property exists
"name" in user;        // true
user.hasOwnProperty("age"); // true
```

### Destructuring, spread, computed keys

```javascript
const user = { name: "Sam", age: 25, role: "admin", city: "Austin" };

// Basic destructuring
const { name, age } = user;
console.log(name); // "Sam"

// Rename while destructuring
const { name: fullName, age: years } = user;
console.log(fullName); // "Sam"

// Default values
const { role = "user", theme = "dark" } = user;
// role = "admin" (from object), theme = "dark" (default)

// Nested destructuring
const { address: { city } = {} } = user; // safe nested

// Rest in destructuring
const { name: n, ...rest } = user;
// n = "Sam", rest = { age: 25, role: "admin", city: "Austin" }

// Spread to clone/merge
const updated = { ...user, age: 26 }; // clone + override
const merged = { ...user, ...{ theme: "dark" } };

// Computed property names
const field = "username";
const dynamic = { [field]: "sam123" }; // { username: "sam123" }

// Shorthand when variable name = key name
const name2 = "Sam";
const age2 = 25;
const person = { name2, age2 }; // same as { name2: name2, age2: age2 }
```
