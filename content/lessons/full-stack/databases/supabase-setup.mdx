## What is it?

Supabase is an open-source Firebase alternative built on PostgreSQL. It provides a database, authentication, file storage, and real-time subscriptions with a clean JavaScript client.

## Why does it matter?

Get a full backend (auth, database, storage) without building a server. Perfect for Next.js apps. The client API is clean and TypeScript-native.

## When and where do you use it?

Building full-stack apps without a dedicated backend. Prototyping, startups, and production apps that don't need custom backend logic.

## How does it work?

Create project at supabase.com → get URL and anon key → install client → use typed client to query your database.

## Examples

### Supabase setup and CRUD

```typescript
// 1. Install: npm install @supabase/supabase-js
// 2. Add to .env.local:
//    NEXT_PUBLIC_SUPABASE_URL=your-project-url
//    NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key

// lib/supabase.ts
import { createClient } from "@supabase/supabase-js";

// Type-safe: generate types from your schema
// npx supabase gen types typescript --project-id your-id > types/database.ts

export const supabase = createClient(
  process.env.NEXT_PUBLIC_SUPABASE_URL!,
  process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY!
);

// ============================================
// CRUD OPERATIONS
// ============================================

// READ — select with filters
const { data: users, error } = await supabase
  .from("users")
  .select("id, name, email")     // specific columns (or "*" for all)
  .eq("role", "admin")           // WHERE role = 'admin'
  .order("created_at", { ascending: false })
  .limit(10);

// SELECT with JOIN (Supabase handles relationships)
const { data: posts } = await supabase
  .from("posts")
  .select(`
    id, title, content,
    users (id, name, email)
  `); // auto-joins via foreign key!

// CREATE
const { data: newUser, error: createError } = await supabase
  .from("users")
  .insert({ name: "Sam", email: "sam@example.com", role: "user" })
  .select()    // return the created row
  .single();   // return object instead of array

// UPDATE
const { data: updated } = await supabase
  .from("users")
  .update({ role: "admin" })
  .eq("id", 1)
  .select()
  .single();

// UPSERT — insert if not exists, update if exists
await supabase.from("profiles").upsert({
  user_id: "uuid-here",
  bio: "Updated bio",
});

// DELETE
const { error: deleteError } = await supabase
  .from("users")
  .delete()
  .eq("id", 1);

// ALWAYS check errors!
if (error) console.error("Supabase error:", error.message);
```

### Supabase Auth

```typescript
import { supabase } from "@/lib/supabase";

// ============================================
// AUTHENTICATION
// ============================================

// Sign up with email/password
const { data, error } = await supabase.auth.signUp({
  email: "sam@example.com",
  password: "supersecret123",
  options: {
    data: { // extra profile data
      name: "Sam Wilson",
      role: "user",
    },
  },
});

// Sign in
const { data: session, error: loginError } = await supabase.auth.signInWithPassword({
  email: "sam@example.com",
  password: "supersecret123",
});

// Sign in with Google (OAuth)
await supabase.auth.signInWithOAuth({
  provider: "google",
  options: {
    redirectTo: `${window.location.origin}/auth/callback`,
  },
});

// Get current user (client-side)
const { data: { user } } = await supabase.auth.getUser();
console.log(user?.id, user?.email);

// Listen for auth state changes
const { data: { subscription } } = supabase.auth.onAuthStateChange(
  (event, session) => {
    if (event === "SIGNED_IN") console.log("Logged in:", session?.user);
    if (event === "SIGNED_OUT") console.log("Logged out");
  }
);

// Sign out
await supabase.auth.signOut();

// Reset password
await supabase.auth.resetPasswordForEmail("sam@example.com", {
  redirectTo: "https://yourapp.com/reset-password",
});
```
