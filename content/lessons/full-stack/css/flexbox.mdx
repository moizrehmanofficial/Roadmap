<BigIdea>
**Flexbox lines things up in a row (or a column) and shares the space between them.** Put `display: flex` on a parent, and its children line up side by side.
</BigIdea>

## At a glance

<Glance>
<What>
A way to arrange items **in one direction**: a row or a column.
</What>
<Why>
Before Flexbox, even "put these two things side by side" or "centre this box" needed tricks. Now it's one or two lines.
</Why>
<When>
Navbars, button groups, a row of cards, an icon next to text, centring something.
</When>
<How>
`display: flex` on the **parent**. Then `gap` for spacing, `justify-content` and `align-items` for alignment.
</How>
</Glance>

## Picture it

Think of **books on a shelf**. The shelf is the **container**; the books are the **items**.

- You can push the books to the left, to the right, or spread them out evenly.
- Short and tall books can sit at the bottom, the top or the middle of the shelf.
- If the shelf is too short, you can start a **second shelf** below.
- Turn the shelf on its side and the books **stack** from top to bottom.

```html preview h=190 noqa
<style>
  body { margin: 0; padding: 12px; font-family: system-ui, sans-serif; }
  .shelf { display: flex; gap: 10px; align-items: flex-end; padding: 10px; border-bottom: 6px solid #92400e; background: #fffbeb; border-radius: 8px 8px 0 0; }
  .book { width: 46px; border-radius: 4px; color: white; font-size: 12px; display: grid; place-items: center; writing-mode: vertical-rl; }
  .label { margin-top: 8px; font-size: 13px; color: #4b5563; }
</style>
<div class="shelf">
  <div class="book" style="height: 100px; background: #b91c1c">item 1</div>
  <div class="book" style="height: 130px; background: #1d4ed8">item 2</div>
  <div class="book" style="height: 80px; background: #15803d">item 3</div>
  <div class="book" style="height: 115px; background: #7c3aed">item 4</div>
</div>
<p class="label">The shelf is a flex <strong>container</strong>. Each book is a flex <strong>item</strong>.</p>
```

## Learn it step by step

<Walkthrough>

<Step title="Turn on Flexbox">

Without Flexbox, `<div>`s stack on top of each other. Add `display: flex` to the **parent** and its children line up in a **row**.

```html preview h=210 noqa
<style>
  body { font-family: system-ui, sans-serif; }
  .box { padding: 10px 14px; border-radius: 8px; background: #fde68a; }
  .row { display: flex; }
</style>
<p>Without flex:</p>
<div>
  <div class="box">One</div><div class="box">Two</div><div class="box">Three</div>
</div>
<p>With <code>display: flex</code> on the parent:</p>
<div class="row">
  <div class="box">One</div><div class="box">Two</div><div class="box">Three</div>
</div>
```

<Happened>

- Only the **direct children** of the flex parent become flex items.
- Each item is only as wide as its content (normal `<div>`s take the full width).
- The row goes left to right. That direction is called the <Def tip="The direction items are placed in. In a row it's left to right; in a column it's top to bottom.">main axis</Def>.

</Happened>

</Step>

<Step title="Add space between items with gap">

`gap` puts space **between** items, but not at the outer edges.

```html preview h=110 noqa
<style>
  body { font-family: system-ui, sans-serif; }
  .row { display: flex; gap: 16px; }
  .box { padding: 10px 14px; border-radius: 8px; background: #fde68a; }
</style>
<div class="row">
  <div class="box">One</div><div class="box">Two</div><div class="box">Three</div>
</div>
```

<Happened>

- Change `16px` to `40px` (press **Edit**) and watch the spacing grow.
- Always prefer `gap` over margins on each item: no extra space after the last item.

</Happened>

</Step>

<Step title="Push items along the row: justify-content">

`justify-content` decides where the **leftover space** goes along the row.

```html preview h=330 noqa
<style>
  body { font-family: system-ui, sans-serif; margin: 8px; }
  .row { display: flex; gap: 8px; padding: 6px; margin-bottom: 4px; border: 1px dashed #9ca3af; border-radius: 8px; }
  .box { padding: 6px 12px; border-radius: 6px; background: #fde68a; }
  .name { font: 13px ui-monospace, monospace; color: #374151; margin: 8px 0 2px; }
</style>
<div class="name">justify-content: flex-start (default)</div>
<div class="row" style="justify-content: flex-start"><div class="box">A</div><div class="box">B</div><div class="box">C</div></div>
<div class="name">justify-content: center</div>
<div class="row" style="justify-content: center"><div class="box">A</div><div class="box">B</div><div class="box">C</div></div>
<div class="name">justify-content: flex-end</div>
<div class="row" style="justify-content: flex-end"><div class="box">A</div><div class="box">B</div><div class="box">C</div></div>
<div class="name">justify-content: space-between</div>
<div class="row" style="justify-content: space-between"><div class="box">A</div><div class="box">B</div><div class="box">C</div></div>
<div class="name">justify-content: space-evenly</div>
<div class="row" style="justify-content: space-evenly"><div class="box">A</div><div class="box">B</div><div class="box">C</div></div>
```

<Happened>

- `center` puts the group in the middle; `flex-end` pushes it to the right.
- `space-between` puts the first item at the left edge, the last at the right edge, and equal gaps in between. That's the classic navbar: logo on the left, menu on the right.
- `space-evenly` makes every gap equal, including the edges.

</Happened>

</Step>

<Step title="Line items up across the row: align-items">

`align-items` decides where items sit **up and down** in the row. This is the other direction, called the <Def tip="The direction across the main axis. In a row it's up and down; in a column it's left and right.">cross axis</Def>.

```html preview h=260 noqa
<style>
  body { font-family: system-ui, sans-serif; margin: 8px; }
  .row { display: flex; gap: 8px; height: 70px; padding: 4px; margin-bottom: 4px; border: 1px dashed #9ca3af; border-radius: 8px; }
  .box { padding: 4px 10px; border-radius: 6px; background: #bfdbfe; }
  .tall { padding-block: 16px; }
  .name { font: 13px ui-monospace, monospace; color: #374151; margin: 6px 0 2px; }
</style>
<div class="name">align-items: stretch (default)</div>
<div class="row"><div class="box">short</div><div class="box tall">tall</div><div class="box">short</div></div>
<div class="name">align-items: center</div>
<div class="row" style="align-items: center"><div class="box">short</div><div class="box tall">tall</div><div class="box">short</div></div>
<div class="name">align-items: flex-end</div>
<div class="row" style="align-items: flex-end"><div class="box">short</div><div class="box tall">tall</div><div class="box">short</div></div>
```

<Happened>

- By default (`stretch`), every item becomes as tall as the row. That's why cards in a flex row all have the same height.
- `center` is what you'll use most: it lines up icons, text and buttons in a toolbar.
- `flex-end` sits everything on the bottom.

</Happened>

<Callout type="tip" title="Easy way to remember">
**justify** = along the row (left ↔ right). **align** = across the row (up ↕ down).
</Callout>

</Step>

<Step title="Let items wrap onto a new line">

By default, items stay on **one line** and get squeezed. `flex-wrap: wrap` lets them move to a new line instead, like the second shelf.

```html preview h=210 noqa
<style>
  body { font-family: system-ui, sans-serif; }
  .tags { display: flex; gap: 8px; max-width: 360px; padding: 8px; border: 1px dashed #9ca3af; border-radius: 8px; margin-bottom: 10px; }
  .tags span { padding: 4px 12px; border-radius: 999px; background: #fef3c7; white-space: nowrap; }
  .wrap { flex-wrap: wrap; }
</style>
<p>No wrap (squeezed and spilling out):</p>
<div class="tags"><span>Organic</span><span>Free delivery</span><span>Gift box</span><span>Same day</span><span>Farm fresh</span></div>
<p>flex-wrap: wrap</p>
<div class="tags wrap"><span>Organic</span><span>Free delivery</span><span>Gift box</span><span>Same day</span><span>Farm fresh</span></div>
```

<Happened>

- Without wrapping, the tags don't fit: they spill out of the box.
- With `flex-wrap: wrap`, the extra tags move to a second line. Use it whenever items have a size they shouldn't go below, especially for phones.

</Happened>

</Step>

<Step title="Make one item take the leftover space: flex: 1">

Give an item `flex: 1` and it **grows** to fill whatever space is left. Perfect for a search box between a logo and a button.

```html preview h=90 noqa
<style>
  body { font-family: system-ui, sans-serif; }
  .bar { display: flex; gap: 10px; align-items: center; padding: 10px; border: 1px solid #e5e7eb; border-radius: 10px; }
  .bar input { flex: 1; min-width: 0; padding: 6px 10px; }
</style>
<div class="bar">
  <strong>Mango Shop</strong>
  <input type="search" placeholder="Search" aria-label="Search">
  <button type="button">Cart (2)</button>
</div>
```

<Happened>

- The logo and the button keep their natural size.
- `flex: 1` tells the input: "take all the space that's left".
- Give **two** items `flex: 1` and they share the space **equally**: that's how you make equal columns.
- `min-width: 0` lets the input shrink on small screens (more on that in "Go deeper").

</Happened>

</Step>

<Step title="Stack items in a column">

`flex-direction: column` turns the row into a **column**. Now the main axis goes top to bottom.

```html preview h=220 noqa
<style>
  body { font-family: system-ui, sans-serif; }
  .card { display: flex; flex-direction: column; gap: 8px; width: 220px; height: 190px; padding: 12px; border: 1px solid #e5e7eb; border-radius: 10px; }
  .card h2 { margin: 0; font-size: 1rem; }
  .card p { margin: 0; color: #4b5563; }
  .card button { margin-top: auto; padding: 8px; }
</style>
<div class="card">
  <h2>Kent mangoes</h2>
  <p>Sweet and fibre-free.</p>
  <button type="button">Add to cart</button>
</div>
```

<Happened>

- The title, text and button stack from top to bottom, with `gap` between them.
- `margin-top: auto` on the button pushes it to the **bottom** of the card. In a row of cards, every button lines up, however long each description is.
- Careful: in a column, `justify-content` works **up and down** and `align-items` works **left and right**. They follow the direction.

</Happened>

</Step>

<Step title="Centre anything in two lines">

Centring something both ways used to be famously hard. With Flexbox:

```html preview h=170 noqa
<style>
  body { margin: 0; font-family: system-ui, sans-serif; }
  .center { display: flex; justify-content: center; align-items: center; min-height: 170px; background: #f3f4f6; }
  .card { padding: 16px 24px; background: white; border-radius: 12px; box-shadow: 0 4px 12px rgb(0 0 0 / 0.1); }
</style>
<div class="center">
  <div class="card">Centred both ways</div>
</div>
```

<Happened>

- `justify-content: center` centres left-right; `align-items: center` centres up-down.
- The container needs some height (here `min-height`), otherwise there's no room to centre in.

</Happened>

</Step>

<Step title="Push one item to the far end">

`margin-left: auto` on one item eats all the free space before it, pushing that item (and anything after it) to the right.

```html preview h=90 noqa
<style>
  body { font-family: system-ui, sans-serif; }
  nav { display: flex; gap: 16px; align-items: center; padding: 10px 14px; border: 1px solid #e5e7eb; border-radius: 10px; }
  .account { margin-left: auto; }
</style>
<nav aria-label="Main">
  <strong>Mango Shop</strong><a href="#">Shop</a><a href="#">Offers</a>
  <a class="account" href="#">My account</a>
</nav>
```

<Happened>

- The logo and links stay on the left, and "My account" goes to the right.
- No extra wrapper `<div>` needed.

</Happened>

</Step>

</Walkthrough>

## Common mistakes

<Compare>
<Bad title="Alignment on the item">

```css
.item { justify-content: center; }
```

`justify-content` and `align-items` do nothing on items.

</Bad>
<Good title="Alignment on the container">

```css
.row { display: flex; justify-content: center; }
```

The **container** arranges its items.

</Good>
</Compare>

<Compare>
<Bad title="No wrap on a phone">

```css
.cards { display: flex; }
```

On a small screen the cards get squashed or overflow.

</Bad>
<Good title="Let them wrap">

```css
.cards { display: flex; flex-wrap: wrap; gap: 16px; }
```

Cards move to a new line when there isn't room.

</Good>
</Compare>

<Compare>
<Bad title="Margins for spacing">

```css
.item { margin-right: 16px; }
```

Leaves extra space after the last item.

</Bad>
<Good title="gap on the container">

```css
.row { display: flex; gap: 16px; }
```

Space only **between** items.

</Good>
</Compare>

<Compare>
<Bad title="Long text overflowing">

```css
.text { flex: 1; }
```

A long URL or word pushes the item wider than the screen.

</Bad>
<Good title="Allow it to shrink">

```css
.text { flex: 1; min-width: 0; overflow-wrap: anywhere; }
```

</Good>
</Compare>

Make the three boxes share the row equally, with 12px between them.

```html preview h=90 noqa
<style>
```

## Remember

<Takeaways>

- `display: flex` goes on the **parent**; its children line up in a row.
- `gap` adds space **between** items.
- **justify-content** = along the row. **align-items** = across the row.
- `flex-wrap: wrap` lets items move to a new line.
- `flex: 1` makes an item take the leftover space.
- `flex-direction: column` stacks items; justify and align then swap directions.
- Centre anything: `display: flex; justify-content: center; align-items: center;`.
- `margin-left: auto` pushes an item to the far end.
- For layouts with **rows and columns** at the same time, use **CSS Grid** (next lesson).

</Takeaways>

<DeepDive title="How flex-grow, flex-shrink and flex-basis share space (with real numbers)">

For each item the browser:

1. Takes its **flex-basis**: its starting size.
2. Adds up all the bases and gaps and compares the total with the container.
3. If there's **space left over**, it shares it out by **flex-grow** (default 0: don't grow).
4. If there's **not enough space**, it shrinks items by **flex-shrink** (default 1: allowed to shrink).

Measured in a real browser (a 600px row; each case sets `flex: grow shrink basis`):

```bash
python3 - <<'PY'
from playwright.sync_api import sync_playwright
cases = {
    "grow 0/0/0 (default)":      ["0 1 100px", "0 1 100px", "0 1 100px"],
    "grow 1/1/1":                ["1 1 100px", "1 1 100px", "1 1 100px"],
    "grow 1/2/1":                ["1 1 100px", "2 1 100px", "1 1 100px"],
    "grow 0/1/0 (search box)":   ["0 1 100px", "1 1 100px", "0 1 100px"],
    "too wide, shrink 1/1/1":    ["0 1 300px", "0 1 300px", "0 1 300px"],
    "too wide, shrink 0/1/1":    ["0 0 300px", "0 1 300px", "0 1 300px"],
}
with sync_playwright() as p:
    browser = p.chromium.launch()
    page = browser.new_page()
    page.set_content("""<!DOCTYPE html><title>t</title><style>body{margin:0}
      #row { display: flex; width: 600px; } #row div { min-width: 0; }</style>
      <div id="row"><div></div><div></div><div></div></div>""")
    for name, flexes in cases.items():
        widths = page.eval_on_selector("#row", """(e, f) => { [...e.children].forEach((c, i) => c.style.flex = f[i]);
            return [...e.children].map(c => Math.round(c.getBoundingClientRect().width)) }""", flexes)
        print(f"{name:26} {widths}  total {sum(widths)}")
    browser.close()
PY
```

```text output
grow 0/0/0 (default)       [100, 100, 100]  total 300
grow 1/1/1                 [200, 200, 200]  total 600
grow 1/2/1                 [175, 250, 175]  total 600
grow 0/1/0 (search box)    [100, 400, 100]  total 600
too wide, shrink 1/1/1     [200, 200, 200]  total 600
too wide, shrink 0/1/1     [300, 150, 150]  total 600
```

- **0/0/0:** each starts at 100px and nobody grows, so 300px stays empty.
- **1/1/1:** 300px left ÷ 3 = 100px extra each, so 200px each.
- **1/2/1:** the middle has twice the grow share: it gets 150px extra (250px), the others 75px extra (175px).
- **0/1/0:** only the middle grows and takes all 300px (the search box pattern).
- **Shrink 1/1/1:** 900px of items in 600px; each gives up 100px.
- **Shrink 0/1/1:** the first refuses to shrink, so the other two give up 150px each.

</DeepDive>

<DeepDive title="flex: 1 vs flex: auto vs flex: none">

| Shorthand | Means | Use for |
| --- | --- | --- |
| `flex: initial` (default) | `0 1 auto` | content size, can shrink, won't grow |
| `flex: auto` | `1 1 auto` | grow and shrink, starting from content size |
| `flex: 1` | `1 1 0%` | **equal** shares regardless of content |
| `flex: none` | `0 0 auto` | fixed at content size |
| `flex: 0 0 250px` | fixed 250px | sidebars, avatars |

Two items with very different text, measured:

```bash
python3 - <<'PY'
from playwright.sync_api import sync_playwright
with sync_playwright() as p:
    browser = p.chromium.launch()
    page = browser.new_page()
    page.set_content("""<!DOCTYPE html><title>t</title><style>body{margin:0; font: 16px monospace}
      .row { display: flex; width: 600px; }</style>
      <div class="row" id="r"><div>Short</div><div>A much longer piece of text</div></div>""")
    for value in ["initial", "auto", "1", "none"]:
        print(f"flex: {value:8}", page.eval_on_selector("#r", """(e, v) => { [...e.children].forEach(c => c.style.flex = v);
            return [...e.children].map(c => Math.round(c.getBoundingClientRect().width)) }""", value))
    browser.close()
PY
```

```text output
flex: initial  [48, 260]
flex: auto     [194, 406]
flex: 1        [300, 300]
flex: none     [48, 260]
```

- **initial / none:** each item is just its content width.
- **auto:** each starts from its content width and the leftover space is split equally, so the longer item stays longer.
- **1:** both start from 0 and share all the space: 300px each, whatever the content.

</DeepDive>

<DeepDive title="The min-width: auto trap (why long text overflows)">

Flex items won't shrink below their **minimum content width** by default: the longest word, a long URL, an image or a code block. So a flex item with a long URL can push past its container.

```bash
python3 - <<'PY'
from playwright.sync_api import sync_playwright
html = """<!DOCTYPE html><title>t</title><style>body{margin:0; font: 16px sans-serif}
.row { display: flex; width: 300px; gap: 8px; }
.icon { flex: none; width: 40px; }
.text { flex: 1; white-space: nowrap; overflow: hidden; text-overflow: ellipsis; }
#a .text { overflow: visible; }
#b .text { min-width: auto; }
</style>
<div class="row" id="a"><span class="icon">📦</span><span class="text">https://mangoshop.example/orders/2026/11/track?id=88412</span></div>
<div class="row" id="b"><span class="icon">📦</span><span class="text">https://mangoshop.example/orders/2026/11/track?id=88412</span></div>"""
with sync_playwright() as p:
    browser = p.chromium.launch()
    page = browser.new_page()
    page.set_content(html)
    for row, label in [("#a", "overflow visible (min-width auto)"), ("#b", "overflow hidden + ellipsis")]:
        w, scroll = page.eval_on_selector(row, "e => [e.querySelector('.text').getBoundingClientRect().width, e.scrollWidth]")
        print(f"{label:34} text item {round(w)}px, row content {scroll}px of 300px")
    browser.close()
PY
```

```text output
overflow visible (min-width auto)  text item 422px, row content 470px of 300px
overflow hidden + ellipsis         text item 252px, row content 300px of 300px
```

- In the first row, the text item refuses to shrink below the URL's length, so the row overflows its 300px container.
- In the second row, `overflow: hidden` lets it shrink to the space left (252px) and show an ellipsis. Writing `min-width: 0` on the item is the usual fix.

</DeepDive>

<DeepDive title="order, row-reverse and accessibility">

- `order: 2` and `flex-direction: row-reverse` / `column-reverse` change only what you **see**.
- Screen readers, the Tab key and copy-paste still follow the **HTML order**, so a reversed layout can confuse keyboard users.
- Only use them when the HTML order still makes sense to read.

</DeepDive>

<DeepDive title="align-self and align-content">

- `align-self` on **one item** overrides `align-items` for just that item: `.badge { align-self: flex-start; }`.
- `align-content` on the container spaces out **whole lines** when items wrap onto several lines and there's extra height. It does nothing on a single line.

</DeepDive>

<DeepDive title="Real-world: from floats to Flexbox">

Before Flexbox (widely supported from about 2015), layouts used **floats**, `inline-block`, tables and negative-margin tricks; vertical centring was a running joke. Bootstrap's grid used floats until version 4 (2018) switched it to Flexbox. Today, Tailwind's `flex`, `justify-between`, `items-center` and `gap-4` classes are these same properties, and React Native uses Flexbox for **all** layout on iOS and Android, with `column` as its default direction.

</DeepDive>

<DeepDive title="Security lens">

- **Visual order vs real order:** `order` and `*-reverse` can show content in a different order than screen readers and copy-paste see. Don't use them to reorder prices, terms or warnings.
- **Truncation hides information:** `min-width: 0` with an ellipsis is great for layout, but for sender addresses, domains and payment recipients, make sure the full value can be seen, so look-alike phishing domains aren't hidden.
- **Spoofed buttons:** injected CSS can use `order` and auto margins to move a fake "Confirm" button where the real one was. Never allow user-supplied styles on your pages.

</DeepDive>

<DeepDive title="Interview questions">

<QA q="What is the difference between the main axis and the cross axis in Flexbox?">
The main axis is the direction items are laid out, set by flex-direction: horizontal for row and vertical for column. The cross axis is perpendicular to it. Justify-content aligns items along the main axis, while align-items, align-self and align-content work on the cross axis.
</QA>

<QA q="What does flex: 1 mean, and how is it different from flex: auto?">
Flex 1 is shorthand for flex-grow 1, flex-shrink 1 and flex-basis 0 percent, so items start from zero and share all the space, giving equal widths regardless of content. Flex auto is grow 1, shrink 1 and basis auto, so items start from their content size and only the remaining space is shared.
</QA>

<QA q="Why does a flex item with long text overflow its container, and how do you fix it?">
Flex items default to min-width auto, which prevents them from shrinking below their minimum content size, such as a long word or URL. Setting min-width 0 on the item, or an overflow value other than visible, lets it shrink so the text can wrap or be truncated.
</QA>

<QA q="When would you use Flexbox instead of CSS Grid?">
Flexbox suits one-dimensional layouts where items flow in a single row or column and their sizes depend on content, such as navbars, toolbars, button groups and card internals. Grid suits two-dimensional layouts where rows and columns must align together, such as page layouts and galleries. They are often combined.
</QA>

</DeepDive>
