## What is it?

Server Components run only on the server — their code never reaches the browser. Client Components run in the browser and support hooks, events, and interactivity. Server is the default.

## Why does it matter?

Server components reduce bundle size, improve performance, and allow direct database access. Client components enable interactive features. Using both optimally is core to modern Next.js.

## When and where do you use it?

Default to Server Components. Add 'use client' ONLY when you need: useState, useEffect, event handlers, browser APIs, or third-party libraries that use hooks.

## How does it work?

Nothing for Server Components (default). Add 'use client' at the very top of the file for Client Components.

## Examples

### Server vs Client Components

```tsx
// =============================================
// SERVER COMPONENT (default — no directive needed)
// =============================================
// ✅ Can: access databases directly, fetch data, use env vars
// ❌ Cannot: useState, useEffect, event handlers, browser APIs

// app/users/page.tsx
import { db } from "@/lib/database"; // direct DB import!

async function UsersPage() {
  // Fetch data DIRECTLY in the component — no useEffect needed!
  const users = await db.query("SELECT * FROM users LIMIT 10");

  return (
    <div>
      <h1>Users</h1>
      <ul>
        {users.map(user => (
          <li key={user.id}>{user.name}</li>
        ))}
      </ul>
    </div>
  );
}

export default UsersPage;

// =============================================
// CLIENT COMPONENT — needs "use client"
// =============================================
// ✅ Can: useState, useEffect, onClick, onChange, browser APIs
// ❌ Cannot: direct DB access, secret env vars

"use client"; // MUST be first line!
import { useState } from "react";

function SearchBar({ onSearch }: { onSearch: (q: string) => void }) {
  const [query, setQuery] = useState("");

  return (
    <input
      value={query}
      onChange={(e) => {
        setQuery(e.target.value);
        onSearch(e.target.value);
      }}
      placeholder="Search..."
    />
  );
}

// =============================================
// PATTERN: Server fetches, Client handles interaction
// =============================================

// app/products/page.tsx (Server Component)
async function ProductsPage() {
  const products = await fetch("/api/products").then(r => r.json());
  
  return (
    <div>
      <SearchBar onSearch={/* ... */} />  {/* Client component inside Server */}
      <ProductList products={products} /> {/* Can be Server if no interactivity */}
    </div>
  );
}
```
