## What is it?

Vercel is the cloud platform built by the creators of Next.js. It automatically builds and deploys your app when you push to GitHub, with zero configuration.

## Why does it matter?

Automated CI/CD means every push to main deploys in ~1 minute. Every PR gets a preview URL. Global CDN means fast loading worldwide.

## When and where do you use it?

The standard deployment target for any Next.js application. Free tier is generous for personal/small projects.

## How does it work?

Connect GitHub repo → Vercel detects Next.js → auto-configures build → deploys. Set environment variables in the Vercel dashboard.

## Examples

### Deploy in 3 steps

```bash
# ============================================
# DEPLOYING TO VERCEL
# ============================================

# Step 1: Install Vercel CLI (optional but useful)
npm install -g vercel

# Step 2: Login
vercel login

# Step 3: Deploy from project folder
vercel        # preview deployment
vercel --prod # production deployment

# ============================================
# Or use GitHub integration (RECOMMENDED):
# 1. Go to vercel.com → New Project
# 2. Import your GitHub repository
# 3. Vercel auto-detects Next.js settings
# 4. Add environment variables
# 5. Click Deploy → done!
# ============================================

# ============================================
# ENVIRONMENT VARIABLES
# ============================================
# In Vercel Dashboard → Project → Settings → Environment Variables
# Add for: Production, Preview, and Development

# .env.local (NEVER commit this file!)
NEXT_PUBLIC_SUPABASE_URL=https://xyz.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGciOiJ...
SUPABASE_SERVICE_KEY=eyJhbGciOiJ...  # server-only, no NEXT_PUBLIC_

# NEXT_PUBLIC_ prefix = exposed to browser
# Without prefix = server-only (secrets are safe)

# ============================================
# .gitignore — what to NEVER commit
# ============================================
# node_modules/       — dependencies (npm install recreates)
# .env.local          — secrets!
# .env*.local         — all local env files
# .next/              — build output (Vercel builds this)
# *.log               — log files

# ============================================
# vercel.json — optional config
# ============================================
```

### vercel.json configuration

```json
{
  "buildCommand": "npm run build",
  "outputDirectory": ".next",
  "devCommand": "npm run dev",
  "installCommand": "npm install",
  "framework": "nextjs",
  "regions": ["sin1"],
  "headers": [
    {
      "source": "/api/(.*)",
      "headers": [
        { "key": "Access-Control-Allow-Origin", "value": "*" },
        { "key": "Access-Control-Allow-Methods", "value": "GET,POST,PUT,DELETE,OPTIONS" }
      ]
    }
  ],
  "redirects": [
    {
      "source": "/old-path",
      "destination": "/new-path",
      "permanent": true
    }
  ],
  "rewrites": [
    {
      "source": "/api/external/:path*",
      "destination": "https://external-api.com/:path*"
    }
  ]
}
```
