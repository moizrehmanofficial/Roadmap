## What is it?

TypeScript adds static type annotations to JavaScript. You tell TypeScript what type each variable, parameter, and return value should be — and it catches mismatches before your code runs.

## Why does it matter?

Catches bugs at compile time instead of runtime. Provides IDE autocomplete and documentation. Makes large codebases maintainable. Required in most modern React/Next.js projects.

## When and where do you use it?

In any TypeScript file (.ts or .tsx). Type annotations are optional but recommended everywhere. TypeScript can infer many types automatically.

## How does it work?

Add : type after variable names, parameters, and function signatures. TypeScript infers types when possible — only annotate when inference isn't clear.

## Examples

### Core type annotations

```typescript
// TypeScript infers types automatically — you don't always need to annotate
let name = "Sam";          // inferred as string
let age = 25;              // inferred as number
let active = true;         // inferred as boolean

// Explicit annotations
let username: string = "Sam";
let score: number = 100;
let isLoggedIn: boolean = false;
let data: null = null;
let x: undefined = undefined;

// Arrays
let scores: number[] = [90, 85, 92];
let names: string[] = ["Sam", "Wilson"];
let mixed: (string | number)[] = ["Sam", 25]; // union type in array

// Tuple — fixed length array with specific types at each position
let point: [number, number] = [10, 20];
let person: [string, number] = ["Sam", 25];

// any — escape hatch, avoid!
let anything: any = "could be anything";
anything = 42;            // no error — any allows this
anything.foo.bar;         // no error — TypeScript gives up on checking

// unknown — safer than any
let value: unknown = getData();
if (typeof value === "string") {
  console.log(value.toUpperCase()); // ✅ must check type first
}

// void — function that returns nothing
function logMessage(msg: string): void {
  console.log(msg);
  // no return statement needed
}

// never — function that NEVER returns (throws or infinite loop)
function throwError(message: string): never {
  throw new Error(message);
}
```
